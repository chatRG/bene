# Code of Conduct

## Our pledge

We want this project to be a place where anyone can learn about health data, scoring models and mobile UI without being made to feel unwelcome. We pledge to make participation harassment-free regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, experience level, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be direct about code and kind about people.
- Assume good intent; ask before assigning motive.
- Give reproducible examples rather than broad criticism.
- Respect privacy. Never ask someone to share real health data, and never post it.
- Accept that maintainers may decline features that conflict with the offline-first, local-only design.

## Unacceptable behaviour

- Harassment, insults, or discriminatory comments.
- Sexualised language or attention.
- Publishing someone's private information without permission.
- Medical advice presented as project guidance.
- Sustained disruption of issues, discussions or reviews.

## Scope

This code applies in repository spaces (issues, PRs, discussions) and when representing the project elsewhere.

## Enforcement

Report concerns to the maintainers through the repository's private contact channel. Maintainers may remove comments, close threads, or block contributors. Reports will be handled as confidentially as possible.
